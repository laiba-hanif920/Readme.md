# Poshaak By Laiba

Premium Pakistani custom fashion e-commerce website. Customers can design their own outfit online, step by step.

## Features

- **Women's Custom Collection:** Kurti, 2 Piece, 3 Piece, Saree
- **Men's Custom Collection:** Casual Shirt, T-Shirt, Formal Shirt, Polo Shirt, Kurta
- **7-step Outfit Customizer:**
  1. Outfit type
  2. Fabric
  3. Colour
  4. Embroidery
  5. Neckline style
  6. Sleeve style
  7. Fitting and measurements
- "How It Works" page explaining the custom tailoring process
- Responsive design for mobile and desktop

## Tech Stack

- HTML, CSS, JavaScript (single file)
- [Tailwind CSS](https://tailwindcss.com/) (CDN)
- [Font Awesome](https://fontawesome.com/) icons
- Google Fonts: Playfair Display, Plus Jakarta Sans

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any browser.

No installation needed. An internet connection is required for fonts and styling (CDN).
